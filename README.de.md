## Funktionen

| Bereich | Was du bekommst |
| --- | --- |
| Klassenlehrer | Jeder Zauber deines Klassenlehrers, gruppiert nach Verfügbarkeit: *Verfügbar*, *Bald verfügbar*, *Noch nicht verfügbar*, *Talente*, *Bekannt*, *Ignoriert* |
| Begleiter-Training | Hexenmeister-Dämonen und Jäger-Begleiter-Fähigkeiten |
| Wildtiere | Jäger-Bestien-Browser mit Zähmbar-Filter, Fähigkeiten, Fundorten und Karten-Pins |
| Lehrer-Karte | Klassen-, Begleiter-, Portal- und Berufslehrer-Standorte mit Wegpunkten |
| Waffen-Skills | Alle Waffenfertigkeiten plus Fundorte der Ausbilder |
| Berufe | Lehrer-Rezepte, sonstige Rezepte (Drops/Händler/Quests), Spezialisierungs-Lehrer |
| Smarte Werkzeuge | Suche, Ignore-Listen, Spoilerfrei-Modus, Preisanzeige mit Ruf-Rabatten, Auto-Zauberränge, kompaktes Kartenlayout |

## Installation

1. `SentinelMentor` nach `Interface/AddOns/` kopieren
2. Spiel neu starten oder `/reload` ausführen
3. Zauberbuch öffnen — die Mentor-Tabs sitzen am rechten Rand

## Bedienung

- `/sentinelmentor` oder der Minimap-Button öffnet die Einstellungen
- Tabs im Zauberbuch und Berufefenster wechseln die Ansicht
- Rechtsklick auf einen Zauber ignoriert ihn (einzelner Rang oder alle Ränge)
- Klick auf Lehrer-Einträge setzt einen Wegpunkt zum nächsten Lehrer
